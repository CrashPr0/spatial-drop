# Cimbar runtime notice

Spatial Drop vendors the browser runtime from `sz3/libcimbar` release `v0.6.8`.
The upstream runtime is licensed under the Mozilla Public License 2.0; see
`LICENSE` in this directory. Spatial Drop adds `bridge.js` and modifies the
upstream sender and receiver HTML shells to support same-origin embedding,
camera cleanup, progress reporting, and in-memory model handoff.
